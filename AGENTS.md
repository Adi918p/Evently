# Project continuity

Before starting any task, read `WORK_LOG.md` and any relevant sections of `AUDIT.md` if present. Respect the current authorized scope recorded there and the user's latest instructions.

After each task, update `WORK_LOG.md` with what changed, the checks actually run and their outcomes, unresolved issues, and the next work to do.

For implementation work, reproduce or establish the issue, implement the requested scope, verify it, and evaluate failures. Repeat the fix/check cycle when needed. Record external blockers and untested flows honestly; never claim the entire application is bug-free based only on a build or syntax check.
